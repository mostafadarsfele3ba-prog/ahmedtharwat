# برنس الرياضيات — مستر أحمد ثروت

ألعاب رياضيات تفاعلية (عربى + English).

- `index.html` : الصفحة الرئيسية — دخول أى درس أو نسخ رابطه.
- `teacher.html` : لوحة المدرس (كلمة سر) — إضافة الطلاب وإنشاء الأكواد، إيقاف/تفعيل، عرض النتائج وتحميلها.
- `lessons/` : كل درس ملف HTML مستقل (6 ألعاب × بنك 150 سؤالًا لكل لعبة، يظهر منها 20 سؤالًا عشوائيًا كل مرة).
  - `p1-ar-1..6` الصف الأول الإعدادى (عربى) — الهندسة
  - `p1-en-1..6` First Preparatory (English) — Geometry
  - `p2-ar-1..6` الصف الثانى الإعدادى — الهندسة
  - `p5-ar-1..3` الصف الخامس الابتدائى — الضرب والقسمة
